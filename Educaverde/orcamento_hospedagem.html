Onde o site está publicado

Comparativo de plataformas de deploy gratuitas

Plataformas avaliadas para publicar o site estático da EducaVerde
Plataforma Custo HTTPS Integração com GitHub Observações
GitHub Pages (escolhida) Gratuito Automático (github.io) Nativa: publica direto do repositório Site de até 1 GB e cerca de 100 GB de tráfego por mês; ideal para HTML, CSS e JS
Netlify Plano gratuito Automático Sim, com deploy a cada push Exige criar conta e conectar o repositório em outro serviço
Vercel Plano gratuito Automático Sim, com deploy a cada push Pensada para frameworks (Next.js); recursos além do necessário
Railway Créditos limitados Automático Sim Voltada a aplicações com servidor; desnecessária para site estático

Por que escolhemos o GitHub Pages

O site da EducaVerde é estático (só HTML, CSS e JavaScript), então não precisa de servidor nem banco de dados. O GitHub Pages publica direto do repositório que a equipe já usa para versionar o código, gera HTTPS automaticamente e não tem custo. Cada commit na branch principal atualiza o site publicado.

Também é a opção de menor impacto ambiental entre as avaliadas: páginas estáticas e leves, servidas por CDN, consomem menos processamento do que um servidor ligado o tempo todo.

Custo para colocar no ar

  • ✔Hospedagem: R$ 0 (GitHub Pages)
  • ✔HTTPS: R$ 0 (certificado automático)
  • ✔Domínio próprio opcional: cerca de R$ 40 por ano no Registro.br (.org.br exige CNPJ de ONG)
